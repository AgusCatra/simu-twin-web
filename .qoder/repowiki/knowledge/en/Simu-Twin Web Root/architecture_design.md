This directory is the Next.js 15 project root; it does not contain application code itself but configures the build/runtime that the `galpon` child module runs inside. `package.json` declares runtime deps (next, react/react-dom, @supabase/supabase-js with SSR helpers, lucide-react, xlsx) and npm scripts (`dev`, `build --turbopack`, `start`, `lint`) that drive the pipeline. `tsconfig.json` enables strict mode, bundler module resolution, JSX preservation, incremental compilation, and an `@/*` path alias pointing at `./src/`. `eslint.config.mjs` uses the flat config format extending `next/core-web-vitals` and `next/typescript`, ignoring generated/third-party directories. `postcss.config.mjs` wires Tailwind CSS v4 through `@tailwindcss/postcss`. `next.config.ts` is present but empty, deferring to Next.js defaults. The `galpon` child module is the only source tree consumed by this configuration.
