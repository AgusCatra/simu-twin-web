Standalone HTML page (no build step) that loads Three.js r128 and OrbitControls from CDNs. Internally organized into numbered sections: constants (`COTA` for calibrated millimeter-scale dimensions, `M` for shared materials), scene/camera/renderer setup, lighting, geometric helpers (`mesh`, `box`, `cyl`, `hinge`), environment primitives (concrete floor, grid, road markings, door outline), two station constructors — `crearEstacion` for seated cockpit simulators and `crearSimspray` for the standing VR paint booth — a static `ESTACIONES` matrix defining positions, rotations, screen layouts and control types, instantiation via `.map()` producing an `INSTANCIAS` array exposed as `window.nave`, a SCADA state layer (`setEstado`) driving emissive screens, point lights, operator visibility and helmet placement, and a render loop applying per-station sinusoidal vibration only to the dynamic cockpit group (`DC`). Dependency direction is one-way: UI buttons → state setters → mesh/material/light updates; no external API or module system is used.
