The root is a thin Next.js shell: `next.config.ts` is empty so behavior comes from defaults plus peer dependencies in `package.json`, while `tsconfig.json` maps `@/*` to `./src/`. The only source tree consumed by the Next.js runtime is the `galpon` child under `src/`; the sibling `scripts` module (ETECH PDF → cohort JSON → Supabase sync) is independent of the Next.js runtime and invoked separately. Cross-child wiring is therefore minimal — both children share the repo's tooling (ESLint 9 flat config, PostCSS/Tailwind v4, Turbopack) but have no runtime coupling.
