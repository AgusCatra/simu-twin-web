Single-script pipeline (`scripts/parse_simuladores.py`) that reads fixed-layout PDFs from `C:\Users\catra\Desktop\Reportes diagnostico nov` via PyMuPDF (`fitz`), renders each page's embedded images (base + SMask) with Pillow, then uses NumPy pixel analysis to reconstruct time-series curves from violet-colored plot lines against a gray grid. The script is organized into layered helpers: low-level image compositing (`curva_de_grafico`), grid-line detection (`filas_grid`), curve extraction (`serie_curva`), per-channel analyzers (`analizar_canal`, `metricas_steering`, `metricas_brake`, `metricas_speed`), log parsers (`parse_portada`, `parse_faltas`), and a classifier (`clasificar`) that maps collision count + steering serrucho index + panic-brake count to `riesgo`/`aptitud`. Each processed PDF yields one record in the output array written to `telemetria_cohortes.json` at the repo root; `_charts/` holds pre-rendered PNG artifacts used as visual evidence of the chart extraction, not consumed by the script.
