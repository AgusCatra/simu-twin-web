The workspace root is a thin Next.js shell: `next.config.ts` is empty so all behavior comes from defaults plus peer dependencies in `package.json`, while `tsconfig.json` maps `@/*` to `./src/`. The only source tree consumed by this configuration is the `galpon` child under `src/`; the sibling `scripts` module (ETECH PDF → cohort JSON) is independent of the Next.js runtime and is invoked separately. Cross-child wiring is therefore minimal — both children share the repo's tooling (ESLint 9 flat config, PostCSS/Tailwind v4, Turbopack) but have no runtime coupling.
