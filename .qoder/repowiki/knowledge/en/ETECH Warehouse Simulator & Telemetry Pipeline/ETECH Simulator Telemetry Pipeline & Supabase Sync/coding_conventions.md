- Per-channel metric functions (`metricas_steering`, `metricas_brake`, `metricas_speed`) all follow the same shape: fetch the image via `analizar_canal(doc, page_no, local_idx, canal)`, return `None` when the channel is missing, and derive counts from boolean masks using `np.sum(mask[1:] & ~mask[:-1]) + edge_head_check` to count transition events.
- Chart pixel decoding uses color thresholds directly on NumPy arrays rather than OCR: violet plot lines are isolated via `(b - g > 25) & (r - g > 15)` and gray grid rows via `abs(r-g)<6 & abs(g-b)<6 & 100<r<245`, with equispaced rows kept by rounding their distance to the median gap within a 0.2-step tolerance.
- Each PDF processing function wraps its body in `try/finally doc.close()` so the PyMuPDF document handle is released even when parsing raises, ensuring resource cleanup across the loop in `main()`.
- External configuration constants (channel indices, `GRID_STEP`, `COVER_FIELDS`, `TYPES`, `RIESGO`, `DICTAMEN`, `MESES`, `STOP`) are declared as module-level uppercase constants near the top of each script rather than passed as arguments.
