Two independent Python scripts form a two-stage pipeline with no shared code:
- `parse_simuladores.py` is the extraction stage: it walks a fixed external directory (`C:\Users\catra\Desktop\Reportes diagnostico nov`), opens each 16-page PDF via PyMuPDF, composites base+SMask images with Pillow, reconstructs time-series curves from violet plot pixels against gray grid lines using NumPy, parses cover/assessment/fault text, classifies risk/aptitude, and writes one record per PDF into `telemetria_cohortes.json` at the repo root.
- `sync_supabase.py` is the ingestion stage: it reads that JSON, fuzzy-matches student names against a hard-coded `NOMINA` roster (ranking/DNI/turno), maps classification strings to Supabase enum values, then upserts cohorts, shift slots, candidates, enrollments, and diagnostic evaluations via the `supabase` client.
Dependency direction is strictly parse → JSON → sync; `_charts/` contains pre-rendered PNG artifacts used as visual evidence of chart extraction but are not consumed by either script. The two scripts share no modules — they communicate solely through the JSON file on disk.
