This module is the project root of a Next.js 15 application bootstrapped via create-next-app. It declares runtime dependencies (next 15.5.25, react/react-dom 19.1.0, @supabase/supabase-js) and dev tooling (TypeScript 5, ESLint 9 with flat config, Tailwind CSS v4 via @tailwindcss/postcss). The app uses Turbopack for both development (`next dev --turbopack`) and building (`next build --turbopack`). TypeScript is configured with strict mode, `moduleResolution: bundler`, JSX preservation, incremental compilation, and an `@/*` path alias pointing to `./src/*`. ESLint uses the flat config format with `next/core-web-vitals` and `next/typescript` presets, ignoring generated/build directories. PostCSS is wired exclusively to `@tailwindcss/postcss`. The `next.config.ts` is present but currently empty, leaving Next.js defaults in place.
