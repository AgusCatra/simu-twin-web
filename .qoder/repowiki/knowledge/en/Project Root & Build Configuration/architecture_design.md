This module is the project root of a Next.js 15 (React 19) application bootstrapped via create-next-app. Runtime dependencies are limited to next, react/react-dom, @supabase/supabase-js with @supabase/ssr helpers, lucide-react icons, and xlsx for spreadsheet handling; all build/lint/tooling packages live in devDependencies. The build/dev pipeline is driven by npm scripts: `dev` runs `next dev`, `build` invokes `next build --turbopack`, `start` runs the production server, and `lint` executes ESLint. TypeScript is configured with strict mode, bundler module resolution, JSX preservation, incremental compilation, and an `@/*` path alias mapping to `./src/*`. ESLint uses the flat config format (`eslint.config.mjs`) extending `next/core-web-vitals` and `next/typescript`, with ignores for generated/third-party directories. PostCSS is wired exclusively through `@tailwindcss/postcss` for Tailwind CSS v4 support. `next.config.ts` is present but empty, deferring to Next.js defaults.
