This module is the project root of a Next.js 15 application bootstrapped via create-next-app. Runtime dependencies are limited to next 15.5.25, react/react-dom 19.1.0, @supabase/supabase-js (with @supabase/ssr), lucide-react icons, and xlsx for spreadsheet handling; all tooling lives in devDependencies. The build/dev pipeline is driven by npm scripts that invoke `next dev`, `next build --turbopack`, and `next start`. TypeScript is configured with strict mode, bundler module resolution, JSX preservation, incremental compilation, and an `@/*` path alias mapping to `./src/*`. ESLint uses the flat config format in eslint.config.mjs extending next/core-web-vitals and next/typescript presets, with ignores for generated/third-party directories. PostCSS is wired exclusively through @tailwindcss/postcss for Tailwind CSS v4 support. next.config.ts is present but empty, deferring to Next.js defaults.
