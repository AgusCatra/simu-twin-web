This directory is a thin Next.js shell: it owns no application code but wires TypeScript (strict mode, bundler resolution, `@/*` alias to `./src/`), ESLint 9 flat config extending `next/core-web-vitals` and `next/typescript`, Tailwind CSS v4 via `@tailwindcss/postcss`, and Turbopack through npm scripts. The only source tree consumed by this configuration is the `galpon` child module under `src/`; `next.config.ts` is empty so all behavior comes from defaults plus the peer dependencies declared in `package.json` (next, react/react-dom, @supabase/supabase-js with SSR helpers, lucide-react, xlsx).
